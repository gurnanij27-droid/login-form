# Login Form using HTML and CSS
About the Project

This project is a simple and attractive Login Form created using HTML and CSS. It provides a user interface where users can enter their email address or phone details and password to log in.

# Technologies Used
HTML5
CSS3
# Features
Clean and simple login form design
Sky blue and purple gradient background
Email input field
Password input field
Forgot password option
Login button
Sign-up link for new users
Centered form layout with rounded corners
# How to Run
Save the code as login.html.
Keep signup.html in the same project folder.
Open login.html in any web browser.
Click the Sign Up link to open the signup page.
Project Structure
login.html – Login form page
signup.html – Signup form page
README.md – Project information
